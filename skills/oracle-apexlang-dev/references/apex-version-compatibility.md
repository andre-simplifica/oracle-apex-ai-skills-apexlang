# Version compatibility

Use [versions and upgrades](versions-and-upgrades.md) for the authoritative gate. This separate kit requires APEX 26.2, SQLcl 26.3+ and ORDS 26.3+. Unknown/newer feature releases need review. The older 24.2 kit is a different repository.

Use APEXlang explicitly as canonical source. SQL recovery is kept separately. Do not request legacy readable YAML as a substitute for APEXlang. A Dynamic Content feature introduced in 22.2 does not reduce this kit's 26.2 minimum.
