# Technical overview

[Compatibility](../templates/compatibility.json) records minimum APEX 26.2, reviewed releases, toolchain prerequisites and no claimed live runtime verification. `apex_version.py` rejects older and unreviewed future feature releases.

`apexlang_tools.py inspect` inventories source and hashes. `validate` invokes SQLcl offline, returns structured compiler diagnostics and records the exact full-tree/deployment/MMD/toolchain evidence. `plan-import` compares the full baseline with a fresh export, checks explicit target mappings and rejects unsupported selected paths/production partial imports. `verify-plan` probes the current SQLcl build and rejects inconsistent evidence, source/configuration/scope changes, drift and plans older than 30 minutes. Reports use `--output` for exclusive creation with private permissions outside application trees. These tools do not parse the complete language, resolve dependency closure, authenticate a live target or execute a plan. See the [daily workflow](../skills/oracle-apexlang-dev/references/daily-workflow.md) for the required inputs and evidence boundaries.

`oracle_reference.py` verifies pinned Oracle inventory hashes and ranks definitions and curated example references, with Portuguese aliases, stable IDs, bounded results and paginated reads. Five patterns use complete Oracle 26.2 application contexts compiled with SQLcl 26.3.1; hashes bind that evidence to the unmodified vendor files. Dependencies/adaptation notes accompany each example, and runtime status remains false. The project installer copies the catalog/evidence with the reference tree and tools, verifies them before writing, and preserves managed-file integrity on updates. See [reference discovery](../skills/oracle-apexlang-dev/references/oracle-reference-policy.md).

The SQL recovery validator, pending migration checker, retention reporter and five-file release validator remain distinct. No command here silently upgrades a database runtime or imports an application.

See [validation](validation.md), [APIs](../skills/oracle-apexlang-dev/references/public-apis-26.2.md) and [release review](../skills/oracle-apexlang-dev/references/release-notes-26.2.md).
