# Adopt the first application

Use [readiness and first baseline](../skills/oracle-apexlang-export/references/readiness-and-first-baseline.md) as the execution procedure. Choose the consuming project, saved connection and application first; this reusable repository contains no live target.

Preserve prior project conventions and application behavior. Start with read-only identity/version checks and fresh exports. Keep the first complete baseline separate from remediation. Use the [readiness template](../templates/readiness-report.md), then run an authorized DEV round trip before declaring readiness.
